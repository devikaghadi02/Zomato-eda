**#Zomato Restaurant Data Analysis Using Python**

**##📖 Overview**
This project performs Exploratory Data Analysis (EDA) on Zomato restaurant dataset to uncover useful business insights such as:
1.Which types of restaurants are most popular
2.How online ordering impacts ratings
3.The relationship between cost, ratings, and restaurant type

**##🔧 Steps Performed:**
Data Cleaning
Removed null values and duplicates
Converted cost column to numeric
Cleaned categorical variables (like restaurant type)
Exploratory Data Analysis (EDA)
Univariate analysis (Restaurant Types, Votes, Ratings distribution)
Bivariate analysis (Cost vs Rating, Online vs Offline orders)
Visualizations with Matplotlib & Seaborn

**##Key Visualizations**
Distribution of Restaurant Types (Bar Plot)
Restaurant Votes Trend (Line Plot)
Online Order vs Offline Order (Bar & Box Plots)
Cost for Two vs Rating (Box Plot)
Heatmap showing correlation between features

**##📊 Insights**
Dining restaurants dominate Zomato listings.
Most restaurants have ratings between 3.0 – 4.0.
Restaurants with online ordering tend to get higher votes.
Cost-effective restaurants are more common than premium ones.
Offline orders usually receive slightly higher ratings than online ones.

**##🚀 Technologies Used**
Python (Pandas, Numpy, Matplotlib, Seaborn)
Jupyter Notebook
